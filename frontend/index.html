    How to Play — Project ECHOES

    1. The 10-Minute Timeline:

    You are trapped inside Astraea Annex 4 where the same 10 minutes repeat endlessly. When the timer hits 00:00, spacetime collapses and the loop resets.

    2. Persistent Notebook:

    All collected documents, codes, and puzzle solutions survive the loop reset. What you learn in Loop 1 remains recorded in Loop 2, 3, and beyond!

    3. Environmental Evolution:

    Subsequent loops reveal new environmental clues—such as a temporal shadow reflection on the corridor glass and decrypted lab safe files.

    4. Three Distinct Endings:

    Solve the 4 interconnected puzzles to reach the Control Room. Choose between breaking the loop, broadcasting the archive, or unlocking the secret harmonic synchronization ending.

    Project Credits

    ECHOES — The Time-Loop Mystery

    Developed as an original computer engineering student project exploring interactive state machines, client-server web architecture, and narrative game design.

    Technologies: Java Standard Edition, Vanilla JavaScript, Semantic HTML5, Custom CSS3.
    Zero external game engines, AI APIs, or CSS frameworks.

    Architecture & Backend Connection

    Project ECHOES features a dual-mode system architecture:

    Local Java Backend Server (port 8080):

    The authoritative Java backend (GameServer.java) runs locally using standard JDK HTTP Server. To compile and run:

    javac -d bin backend/src/*.java
java -cp bin echoes.GameServer 8080
    Web Preview Mode (In-Browser Engine):

    When running inside online sandboxes or without Java installed, the game automatically operates via the built-in local engine (engine.js) with 100% identical state progression, timer, puzzles, and multiple endings.
